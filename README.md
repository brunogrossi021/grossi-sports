\# Grossi Sports



Sistema de gerenciamento de produtos esportivos desenvolvido para fins acadêmicos.



\## Domínio inicial



\- Grupo de produto: classificação dos produtos esportivos.

\- Produto: item esportivo identificado por código, com saldo e valor unitário.



\## Requisitos



\- Java 21

\- Git

\- IntelliJ IDEA Ultimate

\- Docker Desktop



\## Organização do projeto



O sistema será construído incrementalmente durante as aulas da disciplina.



Cada etapa será registrada no Git por meio de commits e tags, permitindo acompanhar a evolução e recuperar estados anteriores do projeto.
